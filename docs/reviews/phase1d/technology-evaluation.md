# Open-source technology evaluation — research snapshot

Date: 2026-11-01. Status: Proposed recommendations, not approved dependencies or commercial/legal clearance. Owner: Architecture lead; required reviewers: security and open-source licensing/commercial specialist. Scope: telemetry collection/storage, visualization and Kubernetes investigation comparators. These tools serve different layers; collectors and dashboards are not equivalent root-cause engines.

## Recommended composition

Keep Cloud Autopsy's evidence/provenance, deterministic reconstruction, ledger and replay contracts owned by the product. Query existing Prometheus/Loki APIs through bounded adapters; PostgreSQL remains the proposed product store. Consider OpenTelemetry Collector as a minimal upstream telemetry pipeline if required; Alloy is an alternative when the environment already standardizes on it. Do not deploy both solely for a comparison. HolmesGPT and K8sGPT are benchmark comparators, not code to fork into the trusted engine. Use synthetic offline fixtures first; avoid new infrastructure and external-model access until separately authorized.

Integration complexity below is our qualitative design estimate, not measured implementation effort. Maintenance observations are release activity, not reliability or vulnerability certification. Recheck pinned artifacts, dependency licenses, advisories and supported versions before implementation and before distribution.

## Commercial decision rules

Apache-2.0 candidates are generally practical integration candidates, subject to notices, applicable patent terms, dependencies and trademarks. AGPL/MPL components are not inherently barred from commercial use; exact obligations depend on what is modified, conveyed and operated. Obtain a qualified review for the intended service/distribution model before bundling, linking/copying code or offering modified services. Keep source/license evidence with the pinned artifact, not only a mutable main-branch URL. Provider terms and model-weight licenses are separate from agent source-code licenses. This research does not accept those obligations on the user's behalf.
