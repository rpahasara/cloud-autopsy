Date: 2026-11-02. Backlog item: [CA-P2-002](../../reviews/phase1d/phase2-backlog.md), first slice per the [CA-P2-002 plan](../ca-p2-001/ca-p2-002-plan.md). Status: bounded preparatory development under product-owner direction D1. Gate D, Gate I, the CA-DEC decisions, security and licensing approvals and merge authorization remain open. Every value below is provisional until an independent architecture reviewer records a disposition (decision D8).

## What the slice provides

| Module | Contract | Purpose |
|---|---|---|
| `src/cloud_autopsy/contracts/errors.py` | Reason codes | `ContractError`, `CanonicalError` and `VersionError`, with 19 pinned codes. Messages never echo document content |

It uses only the Python 3.13 standard library. It performs no I/O beyond the bytes or values passed in. It doesn't import the prototype, the evaluator, the held-out kit or ground truth; tests check this both by inspecting the source and by importing the package in a subprocess.

## Provisional profile (D8 direction)

| Rule | Value |
|---|---|
| Key ordering | UTF-16 code units (RFC 8785 section 3.2.3) |
| Numbers | Integers only, within ±(2^53−1). Fractions, exponents, NaN and Infinity are rejected. Larger and decimal values must be validated string fields in later schemas |
| Strings | UTF-8 without normalization. Only `"`, `\` and U+0000..U+001F are escaped (short forms `\b \t \n \f \r`, others lowercase `\u00xx`). Lone surrogates are rejected |
| Rejected input | Duplicate keys (compared after unescaping), invalid UTF-8, byte-order mark, malformed JSON |
| Ceilings (provisional) | 1 MiB per document, nesting depth 64, 100,000 values. Callers may lower these but never raise them |
| Digest | `ca-jcs-profile-sha256/0.1-provisional:<64 hex>`. Prototype `sha256:` digests are rejected with `digest_algorithm_mismatch`, never reinterpreted |
| Compatibility | Exact version-string match only |

Depth is the number of nested arrays and objects, so `[]` has depth 1. A pre-scan enforces it before the standard-library parser runs. Nodes are counted per value, containers included. The canonical form of an in-memory value is held to the same ceilings, including its encoded size.

## Evidence

- **Vectors:** written by hand from RFC 8785 sections 3.2.2–3.2.3 and the rules above, then cross-checked by an independent JavaScript implementation. That implementation is `JSON.parse`, the default UTF-16 key sort and `JSON.stringify` on Node.js v22.17.0. All 17 valid vectors matched. Node's `crypto` computed the SHA-256 values stored in the vector file. Node is a reviewer's tool, not a dependency; the script is below so it can be rerun.
- **Regressions against the frozen prototype** (read-only comparison): the prototype differs in seven places:
  - **F2:** three UTF-16 ordering vectors;
  - **F3:** it accepts three out-of-range integer vectors;
  - **F1:** a `RecursionError` escapes at nesting depth 100,000.
- **Mutation check:** 10 mutants of `canonical.py` were run and 9 were caught. The caught ones covered code-point sorting, removing the depth pre-scan, each of the two surrogate checks, escaping DEL, uppercase hex escapes, a node-count off-by-one, allowing a BOM, and removing the integer digit-length check. The survivor removed only the parse-time range comparison; the post-parse range check still rejects the same values.
- **Properties:** 300 seeded random values were checked for idempotence, independence from key insertion order and round-tripping. A differential test against `json.dumps(sort_keys=True)` uses keys within the Basic Multilingual Plane, where both orderings agree.

```js
// node jcs-crosscheck.mjs <vector file>
import { readFileSync } from "node:fs";
import { createHash } from "node:crypto";
const doc = JSON.parse(readFileSync(process.argv[2], "utf8"));
const jcs = v => v === null || typeof v !== "object" ? JSON.stringify(v)
  : Array.isArray(v) ? "[" + v.map(jcs).join(",") + "]"
  : "{" + Object.keys(v).sort().map(k => JSON.stringify(k) + ":" + jcs(v[k])).join(",") + "}";
for (const t of doc.valid)
  console.log(jcs(JSON.parse(t.input)) === t.canonical ? "ok" : "MISMATCH", t.id,
              createHash("sha256").update(Buffer.from(t.canonical, "utf8")).digest("hex"));
```

## Not claimed

- **No full RFC 8785 conformance.** The profile excludes floating-point numbers, which make up most of RFC 8785's number serialization. Its vectors are hand-derived by the implementer, cross-checked by one independent implementation, and not yet reviewed by a second person.
- **CI coverage proves conformance to the vectors, nothing more.** The `spike-ci` workflow runs the contract tests on Ubuntu 24.04 with Python 3.13, offline: `python -I -m unittest discover -s tests/contracts -t tests/contracts -v`. The step was added at the product owner's request after the first slice commit. It uses no dependencies, credentials, network access or deployment. A failing contract test exits non-zero, which fails the step and the job. Passing CI shows the code matches the provisional vectors. It doesn't approve the profile.
- **No security or performance approval.** Ceilings are provisional, and parse-time measurements come from one Windows development machine.

## Decisions blocking CA-P2-002b (time intervals)

1. **Timestamp precision:** milliseconds (as in the prototype), microseconds or nanoseconds, and whether finer source precision is kept as raw text only.
2. **Leap seconds:** reject, smear, or keep raw with an unknown parsed time.
3. **Clock steps** within one clock domain during a window: the prototype assumes none. Decide whether a declared step breaks same-domain comparison.
4. **Offset provenance categories:** fixture-declared, measured or unknown, and whether measured offsets are in scope for the MVP (CA-DEC-003).
5. **Time representation in the canonical profile:** epoch milliseconds fit in a safe integer until the year 287,396, so decide between epoch integers and RFC 3339 strings with a fixed fraction length.
6. **Reviewer:** confirm the architecture reviewer for this profile, so its vectors can leave `-provisional` before later contracts depend on its digests.
