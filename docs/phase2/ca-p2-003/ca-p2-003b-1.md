## Focused review before CA-P2-005a (2026-11-10)

This was a self-review of migrations, transactions, roles, credentials and sealing. It is not an independent review.

| ID | Finding | Disposition |
|---|---|---|
| R1 (material) | The intake freeze lived only in Python: `ca_ingest` could skip `ca.ingest_lock_run` and insert batches, delivery receipts or delivered evidence for a sealing or sealed run | **Fixed:** migration `0002_ingest_requires_collecting.sql` adds a `SECURITY DEFINER` `BEFORE INSERT` trigger that takes `FOR SHARE` on the run, refuses with `23514` unless the run is collecting, and serializes against the sealer's phase A. Regression test `test_direct_ingest_rows_rejected_once_run_left_collecting` |
| R2 (material) | If a caller caught a `DbError` inside `Database.transaction()`, PostgreSQL turned the final `COMMIT` into a silent rollback, which the adapter reported as success | **Fixed:** the adapter records any failed statement and raises `25P02` after rolling back. Regression test `test_swallowed_error_is_never_reported_as_commit` |
| R3 | An evidence version is keyed by `(evidence_id, content_digest)`, and its stored record also carries the registry binding digest. A later delivery under a changed registry binding keeps the first stored record | Fails closed: readers decode the record against their own registry and refuse a mismatch. Recorded; no change |
| R4 | If the pure seal raises after phase A (for example `limit_exceeded`), the run stays `sealing` until the lease expires; there is no transition to `failed` | Recorded for the run-lifecycle work |
| R5 | A migration file containing transaction-control statements would break the one-transaction-per-file rule | Files are checksummed and reviewed; no guard added |

## Known limitations

- **Local Docker:** Docker Desktop is installed on the development machine, but its engine wouldn't start (no engine pipe), so integration tests ran only in GitHub CI. Locally they are reported as skipped.
- **Payload purge:** `ca_lifecycle` purge functions, the `ca_truth` schema and the engine role are not implemented (CA-P2-006 and CA-P2-007).
- **Unmeasured:** ingest throughput per run under serialization (CA-DEC-007).
- **Scope:** TLS is off on loopback; this is synthetic-only and must be re-reviewed for any networked use.
